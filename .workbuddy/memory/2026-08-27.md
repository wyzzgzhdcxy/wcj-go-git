# 2026-08-27 工作日志

## Git同步工具 界面与功能改进（第一点）

为 wcj-go-git（Wails + Vue3 + Element Plus 双进程架构）的仓库列表做现代化改造：

### 后端改动
- `app.go`：`GitRepo` 结构新增派生字段 `LastSyncSuccess`（-1 从未同步 / 0 失败 / 1 成功），`LoadGitRepoList` 用子查询从 `sync_logs` 计算每个仓库最新同步状态。
- `sync/main.go`：修复 `gitSync` 失败判定——commit/pull/push 失败时正确置 `Success=false`；修复 `doSync`——失败也写入 `sync_logs` 并更新 `last_sync_time`（原来失败完全不记录，状态点无法反映失败）。

### 前端改动（gitSync.vue）
- 新增同步状态圆点（绿=成功 / 红=失败 / 灰=从未同步 / 浅灰=已禁用），带 tooltip。
- 新增搜索框（按名称/路径/分支过滤）+ 状态下拉筛选（全部/成功/失败/未同步/启用/禁用）。
- 上次同步时间改为相对时间（"x 分钟前"），hover 显示绝对时间。
- 操作按钮由彩色实心改为文字按钮（link），删除增加二次确认弹窗。
- 修复删除按钮在筛选状态下用 `scope.$index` 误删的 bug（改为按 path 查找）。
- 清理残留：移除调用了不存在后端方法 `GetAutoSyncStatus` 的 `checkAutoSyncStatus` 及未使用的 `autoSyncRunning`。
- 样式：行高 36px→48px、增加 hover 高亮、状态点样式。

### 验证
- `go build ./...` 通过；`npm run build` 通过（1424 模块）。
- 注意：vite build 首次因环境 safe-delete 拦截清空 dist 失败，需 `rm -rf dist` 后重跑。

### 架构备忘
- 主应用 app.go 与 sync 服务（sync/main.go，监听 localhost:19090）是**两个独立可执行文件**。
- 前端入口：`frontend/src/pages/js/index.js` 直接挂载 `gitSync.vue`（无 router）。
- 手动同步前端传的 repos 参数实际被忽略，sync 服务从缓存同步所有启用仓库（已知架构局限）。

### 后续微调
- 行高 48px → 40px（用户反馈太挤，取中间值），padding 6px → 4px。
- 关键经验：前端改动必须 `wails build` 重新打包（前端 dist 通过 go:embed 打进 exe），仅 npm run build 不生效——用户第一次"看不到改动"就是因为运行了旧 exe。
